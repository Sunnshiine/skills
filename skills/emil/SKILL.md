Each skill lives at `../<name>/SKILL.md` from this file. Pick every skill whose entry matches the task, and read each one's SKILL.md in full.

## Build

- **animate.** Building new web motion.
- **animate-expo.** Any motion in React Native or Expo: gestures, haptics.
- **apple-design.** Apple-style fluid UI on the web: springs, gestures, materials, typography.
- **mobile-native.** A web app that must feel installed on a phone: 100vh, input zoom, tap highlights, the notch, PWAs.
- **prototype.** Several versions of a UI piece to flip between.
- **ask-sonner.** Setting up or troubleshooting Sonner toasts.
- **pick-ui-library.** Choosing a library for a frontend job.
- **write-swift.** Writing, reviewing, or migrating Swift.

## Review and fix

- **emil-design-eng.** Polishing or critiquing UI craft. The general taste reference.
- **review-animations.** Reviewing a diff or file of animation code.
- **animation-performance.** Web motion that drops frames, or picking properties to fit the frame budget.
- **break-ui.** Stress-testing a component with worst-case data.

## Audit (read-only)

- **improve-animations.** Auditing a whole codebase's motion.
- **find-animation-opportunities.** Finding places that don't animate but should.

## Reference

- **animation-vocabulary.** The user describes a motion effect and needs its name.
