Each skill lives at `../<name>/SKILL.md` from this file. Pick every skill whose entry matches the task, and read each one's SKILL.md in full.

## Foundation

- **design-foundations.** The layout or hierarchy is wrong: spacing, alignment, button hierarchy, empty states, microcopy.
- **typography.** The text itself: fonts, type scales, line length, wrapping, truncation.
- **color.** Picking or auditing color values: OKLCH palettes, scales, dark-mode values, contrast.

## Build

- **animate.** Building new web motion.
- **animate-expo.** Any motion in React Native or Expo: gestures, haptics.
- **apple-design.** Apple-style fluid UI: springs, gestures, materials, typography.
- **surfaces.** Shadows, borders, gradients, elevation, and their dark-mode versions.
- **component-design.** The props API of a reusable React component.
- **forms-and-inputs.** Forms, inputs, buttons, validation, submit behavior.
- **marketing-pages.** Landing pages, blogs, docs sites, changelogs.
- **mobile-native.** A web app that must feel installed on a phone: 100vh, input zoom, tap highlights, the notch, PWAs.
- **prototype.** Several versions of a UI piece to flip between, before the design is decided.
- **ask-sonner.** Setting up or troubleshooting Sonner toasts.
- **pick-ui-library.** Choosing a library for a frontend job.
- **write-swift.** Writing, reviewing, or migrating Swift.
- **design-system-docs.** Writing a DESIGN.md so agents pick the right component, variant, and token.

## Review and fix

- **emil-design-eng.** The general taste reference for UI craft.
- **ui-polish.** The layout is right but feels unfinished: rendering, states, hit areas, layout shift. Fixes it.
- **ui-review.** Findings on a UI diff or generated component, ranked by harm. Reports only.
- **animations.** Motion that looks wrong: whether to animate, easing, duration, springs, enter and exit.
- **review-animations.** Reviewing a diff or file of animation code.
- **ask-lapse.** Seeing what an animation does frame by frame with Lapse.
- **animation-performance.** Motion that drops frames.
- **performance.** Slow UI beyond motion: long lists, loading, fonts and images, re-renders, layout shift.
- **touch-and-accessibility.** Someone is locked out: tap targets, focus, keyboard, screen readers, reduced motion.
- **unslop-design.** A screen that looks AI-generated or generic.
- **break-ui.** Stress-testing one component with worst-case data.

## Audit

- **improve-animations.** Auditing a whole codebase's motion. Read-only.
- **find-animation-opportunities.** Finding places that don't animate but should. Read-only.
- **prep-for-prod.** Sweeping the whole app before a launch, then fixing what a diff can fix.

## Vocabulary

- **animation-vocabulary.** The name of a motion effect.
- **design-vocabulary.** The name of something you can see, or the right word between near-synonyms.
- **engineering-vocabulary.** The name of a frontend behavior or pattern.
