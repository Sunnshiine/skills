# Emil router

Match the task to every branch below it touches, then invoke those skills in order: build before review.

## Invoke with the Skill tool

| Branch | Skill |
| --- | --- |
| Build new web motion | `animate` |
| Build motion in React Native or Expo | `animate-expo` |
| Web motion drops frames | `animation-performance` |
| Name a motion effect the user describes | `animation-vocabulary` |
| Apple-style interfaces | `apple-design` |
| Sonner toasts | `ask-sonner` |
| Stress-test a component with worst-case data | `break-ui` |
| Polish or critique UI and existing motion | `emil-design-eng` |
| Find what should animate but doesn't | `find-animation-opportunities` |
| Audit a codebase's motion into a fix plan | `improve-animations` |
| Web app that must feel native on a phone | `mobile-native` |
| Swift | `write-swift` |

## Ask the user to type these

When one matches, stop and name the command for the user to run.

| Branch | Command |
| --- | --- |
| Strict review of animation code, where `emil-design-eng` is the lighter default | `/review-animations` |
| Several UI variants behind a live picker | `/prototype` |
| Choose a frontend library | `/pick-ui-library` |
